- Como explicar

- Contexto
    Empresa atual ou anterior? (Não falar o nome da empresa)
    Escopo da empresa/produto/serviço
    Problema a ser resolvido
    Prejuizos do problema

- Solução  
    - Frases para iniciar uma solução: 
        - In order to solve this (problem)
        - our solution to solve this (problem)
    - Ideia central para resolver o problema
    - Escopo do time e do tempo
    - Tecnologias
    - Metodologias e detalhadamento (o nivel de detalhadamento vai ser diferente diferente da pessoa).
    - Implicitamente mostrar valores (ownership, trabalho em equipe)

- Resultado
    - Frases para iniciar o resultado:
        - as a result
    - Problema que foi resolvido
    - Quantificadores
    - Qualificadores
