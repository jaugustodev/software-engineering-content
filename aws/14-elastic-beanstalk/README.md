# AWS Elastic Beanstalk

## Hands-on para assistir

| Aula | Por que assistir |
|------|-----------------|
| Beanstalk First Environment | Ver o fluxo completo de deploy de uma app — escolha de plataforma, configurações, logs |
| Beanstalk Second Environment | Ver como criar environment de staging/prod e fazer swap de URLs |
| Beanstalk Deployment Modes Hands On | Ver All-at-once vs Rolling vs Blue/Green na prática — diferenças ficam mais claras visualmente |
