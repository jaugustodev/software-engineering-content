# AWS Monitoring & Audit: CloudWatch, X-Ray and CloudTrail

## Hands-on para assistir

| Aula | Por que assistir |
|------|-----------------|
| CloudWatch Logs - Hands On | Ver como navegar em log groups, filter patterns e insights — interface não é óbvia |
| CloudWatch Alarms Hands On | Ver configuração de alarme com ação (SNS, EC2 action) |
| Amazon EventBridge - Hands On | Ver criação de rule com schedule e pattern matching — muito usado para automação |
| X-Ray Hands On | Ver o service map e traces no console — a visualização é o ponto forte |
| CloudTrail Hands On | Ver como buscar events e configurar trail para S3 |
