# AWS Serverless: DynamoDB

## Hands-on para assistir

| Aula | Por que assistir |
|------|-----------------|
| DynamoDB Basics - Hands On | Ver criação de table, partition key, sort key e inserção de items |
| DynamoDB WCU & RCU - Hands On | Ver como configurar capacity e entender throttling na prática |
| DynamoDB Basic APIs - Hands On | Ver GetItem, PutItem, Query e Scan via console/CLI |
| DynamoDB Streams - Hands On | Ver configuração de stream e integração com Lambda |
| DynamoDB CLI | Ver comandos essenciais de leitura/escrita via CLI — muito útil no dia a dia |

- DynamoDB DAX - Hands On (pode pular)

- DynamoDB Transactions (ACID para múltiplos items)
- DynamoDB Session State (usar DynamoDB como session store)
- DynamoDB Partitioning Strategies (hot partition problem)
