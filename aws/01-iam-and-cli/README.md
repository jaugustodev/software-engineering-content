# IAM & AWS CLI

## Hands-on para assistir

| Aula | Por que assistir |
|------|-----------------|
| IAM Users & Groups Hands On | Ver o fluxo de criar usuários/grupos no console pela primeira vez |
| IAM Policies Hands On | Ver como policy JSON é estruturado e como aplicar no console |
| IAM MFA Hands On | Configuração de MFA tem passos específicos no console |
| AWS CLI Hands On | Ver como configurar `aws configure` e rodar primeiros comandos |
| AWS CloudShell | Ferramenta útil do console, vale ver 3 min |
| IAM Roles Hands On | Ver como criar e associar role a um serviço |
| IAM Security Tools Hands On | Ver o Credential Report e Access Advisor no console |

## Teoria que posso explicar (pode pular as aulas)

- IAM Introduction: Users, Groups, Policies
- IAM Policies (conceitos)
- IAM MFA Overview
- AWS Access Keys, CLI and SDK
- IAM Roles for AWS Services
- IAM Security Tools
- IAM Best Practices
- Shared Responsibility for IAM
- AWS CLI Setup (Windows/Mac/Linux) — só instala o CLI, não precisa assistir
- AWS Budget Setup — só configurar alertas de custo
